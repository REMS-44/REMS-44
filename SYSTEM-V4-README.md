# Публічний сайт V4

- Поле `group` з Firebase має пріоритет над початковим списком.
- Якщо групу студента змінено у REMS Control, після публікації сайт показує нову групу.
- Вкладки груп генеруються автоматично.
- Нові опубліковані студенти, яких немає у початковому списку, додаються автоматично.
- Загальний список «Усі» сортується за ПІБ по алфавіту незалежно від групи.
