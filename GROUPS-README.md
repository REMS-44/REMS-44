# Групи студентів

Поточна видима назва сайту: **Майстерня режисури**.

Сайт має канонічний список 34 студентів і зводить його з опублікованими даними Firebase
за `id`, `studentId` або ПІБ (із підтримкою коротких імен на кшталт Даша/Дар'я, Катя/Катерина).
Старі профілі не дублюються: фото, портфоліо та інші дані з Firebase підтягуються в одну канонічну картку.

Групи не зашиті в інтерфейс: вкладки створюються автоматично з поля `group`.
Майбутні нові опубліковані студенти/групи можуть додаватися автоматично.

Технічну адресу GitHub Pages та внутрішні ключі `rems44_*` не перейменовано,
щоб не ламати персональні посилання, встановлені вебзастосунки та push-підписки.

## Автоматичні нові групи

- Загальний список «Усі» сортується за ПІБ по алфавіту, незалежно від групи.
- Вкладки груп створюються автоматично з унікальних значень поля `group`.
- Якщо в REMS Control з'явиться студент нової групи і його публічний профіль буде опублікований у `rems_public_profiles`, сайт автоматично підтягне цього студента і створить вкладку нової групи.
- Окремо прописувати РЕМС-24, РЕМС-54 тощо в коді сайту не потрібно.
