# Групи студентів — як додавати нові

Система тепер не прив'язана до двох конкретних груп.

- У REMS Control поле `group` є частиною картки студента.
- Фільтри груп будуються автоматично з унікальних значень `student.group`.
- На публічному сайті вкладки груп також створюються автоматично з даних студентів.
- Щоб додати РЕМС-24 / РЕМС-54 тощо, достатньо додати студентів із новим значенням `group`.
- Поточна видима назва сайту: **Майстерня режисури**.
- Технічну адресу GitHub Pages і внутрішні ключі `rems44_*` навмисно не перейменовано, щоб не зламати персональні посилання, встановлені вебзастосунки та push-підписки.
